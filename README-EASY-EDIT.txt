NOIREN EASY-EDIT VERSION

HOW TO CHANGE:
1. Open EDIT-ME.json in any text editor.
2. Change brand name/tagline/WhatsApp/Instagram and product names/prices.
3. Save EDIT-ME.json.
4. Upload the whole website folder to Netlify as a new deploy.

PRODUCT IMAGES:
The current demo uses the existing visual/product styling. For real product photos, replace the image assets and update the HTML if needed.

IMPORTANT:
- Replace 919999999999 with your real WhatsApp number including country code, without + or spaces.
- The website does NOT have online payment yet.
- Keep EDIT-ME.json in the same folder as index.html.
